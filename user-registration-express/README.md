# User Registration - Express.js

## Run locally

1. Install Node.js.
2. Open a terminal in this project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Open http://localhost:3000/user_reg in your browser.
6. Fill in the form and click Submit. The submitted details appear on the next page.

The registration form is stored in `public/user_reg.html`.
